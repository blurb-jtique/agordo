# Bookserve installation Java in Mac M3

## Installing Java

```sh
sdk install java 8.0.452-amzn
```

## Installing Maven

3.8.x ✅ Fully compatible with Java 8. Includes improved TLS support and warnings for Java 9+

```sh
sdk install maven 3.8.9
```

## Installing Tomcat

```sh
sdk install tomcat 9.0.104
```
